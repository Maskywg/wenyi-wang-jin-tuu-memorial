[閱讀紀念網頁](https://maskywg.github.io/wenyi-wang-jin-tuu-memorial/)

- 電信生涯與公開史料
- 文宜輸入法的文化與宜人設計理念
- 繁體中文、字形與 AI 研究的對話
- 家人的追念與寄語
